# B5 — conversión de apariencia nativa AA8

Este bloque recupera conversiones, asignaciones de armas y armaduras,
reactivos de conversión y reactivos de reversión desde `game11`, usando los
layouts confirmados en `x2game.dll`.

El catálogo es de consulta. La mutación queda bloqueada hasta confirmar el
protocolo AA8 y construir una transacción atómica con rollback.
