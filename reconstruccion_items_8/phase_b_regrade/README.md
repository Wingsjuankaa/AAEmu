# B4 — regrade nativo AA8

Este bloque reemplaza el catálogo híbrido de regrade por las cuatro tablas
confirmadas en `game11` y `x2game.dll`: grupos, ratios, asignación de objetos y
soportes.

El artefacto es deliberadamente de consulta. No habilita el regrade porque la
transacción, el consumo económico y las recompensas de rotura todavía no están
confirmados de extremo a extremo para AA8.

La compact 3.0 no participa en la extracción ni aporta valores de fallback.
